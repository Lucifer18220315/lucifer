# Готовка

**Состояние:** пользователь хочет изучать и, возможно, развивать тему. Навыки, рецепты и формат блога пока не установлены.

Предложения для исследования:

- Простое блюдо с честным показом процесса и результата.
- Еда под повседневный режим и тренировки без неподтверждённых диетических обещаний.
- Один кулинарный навык, освоенный и повторённый на практике.

До производства выяснить доступную кухню, предпочтения, ограничения питания, время и стоимость блюда. Рецепт должен иметь конкретные количества, шаги, реальное время и проверенный результат; не считать переписанный рецепт приготовленным.

Связь с личным блогом возможна через повседневность. Самостоятельный кулинарный блог и частота выпусков пока не утверждены.
