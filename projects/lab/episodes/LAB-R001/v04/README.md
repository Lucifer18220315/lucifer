```bash
npm ci

npm run check
npm run check:v04

```

Команды выполняются из `../video`. Для упаковки нужна сохранённая звуковая дорожка референса `public/v04-reference-audio.m4a`. Она исключена из Git и не объявляется оригинальным звуком. Если разрешённый для работы файл референса доступен на сервере, дорожку можно извлечь без перекодирования:

```bash
ffmpeg -i /tmp/playboy-editing-series/DcjNPkZB_KF.mp4 -vn -c:a copy public/v04-reference-audio.m4a
```

Это контрольное сравнение с исходным монтажом и музыкой. Публикация в соцсетях не выполняется.

## Что редактируется

В Remotion есть `FullRemakeV04`, двенадцать композиций в `V04-Shots` и `EditV04` с двенадцатью отдельными видеоклипами. Есть 12 основных плановых групп; внутри листания восстановлены четыре чертежа и короткая смена вида. Порядок и длины — 94/60/15/31/31/38/61/14/9/13/26/31 кадр. Всего 423 кадра при 2997/125 fps. `FullRemakeV04Motion` позволяет проверить анимацию с удвоенной частотой.

Подвижные планы рендерятся с двумя временными выборками на исходный кадр, затем FFmpeg усредняет соседние выборки внутри клипа. Через границы склеек усреднения нет. Световые состояния намеренно остаются дискретными. Чтение всех 38 кадров уточнило прежнюю ошибку: складывание идёт непрерывно вместе с подъездом камеры; оно больше не заморожено в шесть состояний. Это двухвыборочное приближение затворного размытия, не физическая симуляция камеры.

Финальные клипы — 720 × 1280. Canvas действительно рассчитывается в этом размере, скрытого 1080p нет; увеличенный CSS-контейнер не добавляет деталей. Клипы собираются последовательно, внутри одного клипа работает один поток захвата, чтобы не конкурировать за программный WebGL. Сервер использует программный WebGL. В планах «свет», «обход стола», «чертёж», «налив» сохраняется карта теней: источники и отбрасывающие тени предметы не движутся. Включение света обновляет карту; подвижные руки, бумага, сгибы и часы обновляют её на каждом временном отсчёте. Все клипы приводятся к одному диапазону TV и матрице BT.709 перед объединением, чтобы метаданные цвета не менялись на склейках.

Кэш рендера связан с SHA-256 содержимого `src/v04`. Для точечной повторной сборки: `npm run render:v04 -- --only=PourV04 --force`. Упаковка сверяет контрольные суммы и число кадров каждого клипа. Она не заменяет визуальный просмотр.

## Ассеты и границы результата

Бумага, древесина и HDR повторно используются из [CC0-манифеста v03](../video/assets/v03-manifest.json). Рука — [WebXR generic-hand](../video/assets/v04-manifest.json), MIT, © 2019 Amazon; [полный текст лицензии](../video/assets/licenses/webxr-hand-MIT.md) сохранён. Сетка сглажена одним шагом Loop с сохранением костей и весов; пальцы получают точки контакта. Перегенерация: `npm run smooth-hand:v04`.

Сцены, чертежи, карточка и маркировка созданы для Playboy. Это компьютерная реконструкция: рука остаётся стилизованной, вода — геометрическая струя с преломлением, без гидродинамической симуляции. Покадровые границы можно повторить точно; идентичность живой фактуры оригиналу этим не достигается. Просмотры, удержание и сохранения не проверены. Помощник не заявляет субъективное прослушивание.

MP4, временные кадры и тяжёлые карты находятся на сервере и исключены из Git. Предыдущие v01/v02/v03 сохранены.

После D022 используется [сетка наблюдений часов](clock-native-frames.json) и [подгонка силуэта складывания](fold-camera-fit.json). Подгонка по нескольким экранным ориентирам не восстанавливает единственную физическую камеру оригинала. Отдельные неизменённые клипы сохраняются между правками; машинный отчёт хранит SHA фактического исходника каждого рендера, без переименования старых клипов в новую ревизию.

D022: `audit:v04` создаёт 423 нативные пары и 1051 отметку с шагом 16,8 мс. На частой сетке исходные кадры удерживаются, оптическая интерполяция не применяется. Само извлечение изображений не является доказательством выполненного просмотра; фактический объём проверки фиксируется отдельно в разборе.
