# LAB-R001 v04.1 — минималистичный текст и очистка метаданных

2026-11-07, Europe/Moscow. [Готовый MP4](/workspace/shared/downloads/LAB-R001-v04-1-text-clean.mp4), [пять подписей](/workspace/shared/downloads/LAB-R001-v04-1-text-check.jpg), [проверки файла](report.json).

По последнему уточнению пользователя сохранён исходный минимализм: пять однострочных подписей света без плашек и обводки, Arial 500, прежний светлый цвет и экранные позиции. Размер увеличен с 18 до 24 пикселей в 720 × 1280, добавлена слабая тень 1/2 px для контраста. Физическая печать на предметах этой правкой не менялась.

Первый план собран из шести чистых состояний актуальной 3D-сцены и отдельных текстовых слоёв. Чистые состояния перерендерены из текущего кода; не заявляется попиксельная идентичность его фона прежнему закэшированному плану v04. Остальные 329 кадров f94–422 совпадают с v04 по хешам декодированных изображений. Прежний файл и его [аудит 24 расхождений](../v04/audit.md) сохранены; этот текстовый экспорт не закрывает точность ремейка C001-09.

Из MP4 убраны описательные теги, сведения об энкодере, H.264 SEI и встроенный ICC-профиль. Необязательные MP4-блоки заменены пустыми блоками той же длины, чтобы сохранить адреса медиаданных. Обязательные поля формата и технические параметры H.264/AAC/BT.709 оставлены. Это обычная очистка метаданных, не утверждение об изменении происхождения контента.

## Звук и CapCut: остаются открытыми

Пользователь уточнил: **уменьшить только эффекты до 85%, музыку сохранить**. В v04 есть единая дорожка референса Austen Paul, отдельных SFX/музыки нет. Общая громкость не уменьшалась: все 382 закодированных аудиопакета совпадают с v04. Избирательное снижение эффектов пока не выполнено; нужны отдельная дорожка эффектов и музыка либо проект с раздельным звуком. Автоматическое выделение эффектов с гарантией неизменности музыки не заявляется.

Пользователь поручил экспорт через CapCut на своём ПК. Доступа к его рабочему столу/локальному CapCut в текущем наборе инструментов нет. Экспорт через CapCut и сохранение на ПК не выполнены. Облачная среда не объявляется пользовательским ПК; никакие настройки среды не менялись и не публиковались.

## Воспроизведение на сервере

Из `../video`:

```bash
npm run check
npm run render:v041
npm run package:v041
```

`render:v041` делает шесть чистых PNG из 3D и собирает 94 кадра с отдельной типографикой. PNG сохранены небольшими ассетами. `node scripts/render_v041.mjs --reuse-plates` повторяет только текстовую сборку из уже подготовленных состояний. `package:v041` использует сохранённые клипы v04 и серверный исходный MP4; тяжёлые MP4 в Git не включаются.

Упаковка проверяет полное декодирование, 423 кадра, 720 × 1280, 2997/125 fps; тождество аудиопакетов и всех 329 кадров после вступления; отсутствие тегов энкодера и ICC после очистки. Пять финальных состояний текста проверяются изображением. Субъективное прослушивание не заявлено.
