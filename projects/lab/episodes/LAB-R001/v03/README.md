## Воспроизведение на сервере

Рабочий каталог: `projects/lab/episodes/LAB-R001/video`.

```bash
npm ci
npm run assets:v03
npm run check
npm run check:v03
npm run render:v03
npm run package:v03
```

`assets:v03` загружает CC0-карты и сверяет хеши с сохранённым манифестом. Использовать штатный HTTPS-прокси и доверенные CA среды; не отключать TLS-проверку.

Предрасчёт сгибов уже сохранён в `assets/v03-cup-occlusion.json`. После изменения геометрии, позиции предмета или света выполнить `npm run bake:v03`, затем проверки и рендер. Проверка SHA-256 запрещает использовать данные от другой геометрии.

`render:v03` использует системный Chromium `/usr/bin/chromium`, программный WebGL, два потока рендера и нативный Canvas 1080 × 1920. `package:v03` создаёт собственную звуковую дорожку, MP4, контрольные листы, схему и ZIP исходников в `/workspace/shared/downloads`. Для него нужны FFmpeg, Python, NumPy и Pillow; экспорт PNG схемы дополнительно использует CairoSVG либо Inkscape, SVG сохраняется всегда.

Для просмотра: `npm run studio`, композиция `FoldLightV03`. HTML-плеер расположен в `public/watch-v03.html`, после упаковки рядом с ним доступны видео и схема. Remotion обслуживает public по текущему префиксу `static-*`; буквальный `/public/` не является адресом этих файлов.

Медиа и карты остаются серверными артефактами. В Git хранятся код, небольшие данные предрасчёта, параметры, ссылки, хеши и результаты проверок. Mac пользователя не используется.
