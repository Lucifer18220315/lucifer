## Реализация

- Совместная подгонка одной формы стакана, положения/размеров часов и четырёх камер по рамкам и видимым рёбрам. Это экранная реконструкция с погрешностью ручной разметки, не восстановление настоящего объектива автора. [Совместный расчёт](joint-scene-fit.json), [складывание](camera-fit.json), [возврат/макро](detail-fits.json).
- Световые переходы получены из измерений яркости областей референса. Время подписи отделено от изменения света. У проектора фоновой маски исправлена ближняя граница: стандартные 0,5 м исключали близкую стену из проекции. Диагональное пятно проверено новым рендером; оно ещё отличается от исходного по профилю и оттенку.
- Дальний фон обхода восстановлен отдельно: [параллакс и ограничения](background-fit.json), открытый проигрыватель с пластинкой/тонармом и полка с книгами, рюкзак, окно; фокусировка отделяет их от переднего предмета. Ближняя стена прежнего общего плана не навязывается обходу. Новые шарнирные клапаны с вырезом, отдельное открытое состояние для налива, согласованная печать; физический разворот с корешком и двумя полями, перспективной комнатой и рисунком стакана в последних трёх кадрах. [Граница листа/корешок](notebook-fit.json) использованы для камеры и высоты разворота. Исправлено направление: от верхней стопки вниз, без подъёма листа выше пальцев.
- Появление надписи после прохода руки, более позднее касание карандаша, его ракурс/заточка/износ и линованная бумага; обновлённые инструменты, смятые листы, опора и материалы. Повторный просмотр трёх ракурсов уточнил диаметр/поворот транспортира, его плотную разметку и частичное перекрытие ковриком; вход и остаток подгонки — [protractor-fit.json](protractor-fit.json), положение края коврика — [mat-fit.json](mat-fit.json), листа и карандаша — [paper-prop-fit.json](paper-prop-fit.json). Передний лист в обходе отодвинут: прежний закрывал инструмент и начинался слишком высоко.
- Реальное усреднение субкадров собственного 3D-движения: четыре выборки на быстрых проходах, две на остальных движущихся планах. К исходному видео интерполяция не применяется.

## Хук

По наблюдаемому монтажу Caldera: общий план установки → деталь того же объекта → собранный кадр. Первый тёмный общий план отклонён после просмотра всех его кадров: оборудование не читалось. В отдельной V05B камера вынесена крупно на передний план, добавлены её крепления/управление, полноценные стойки, кабели, пол/стена студии и проезд. Это перенос композиционного приёма Caldera, а не заявление о совпадении оборудования автора. [Координаты нашей композиции](bts-camera-fit.json) задают читаемость своего кадра, не восстановление его камеры. Первые 94 кадра делятся на **36/30/28**: склейки на 1,5015 и 2,7528 с. Съёмочные сцены и изображение на дисплее камеры — наши серверные 3D-рендеры. Графика разворота восстановлена из цветных штрихов референса; это явно перенесённый графический слой, а не самостоятельное авторство рисунка. Фотографические кадры, исходные бумага/кожа/фон в экспорт не входят.

Переключения света сохраняют исходные времена, чтобы не переносить их произвольно относительно звука. В основном варианте нет вопроса и названий источников поверх кадра; пять минимальных подписей сохранены в контрольном вступлении. Связь «установка → результат» имеет источник; эффективность для нашей аудитории ещё не измерена. Вариант с исходным вступлением сохраняется как контроль для сверки, основная выдача — вариант с хуком.

## Проверки и ограничения

Просмотрены все 423 кадра контрольного монтажа на 18 листах нативных наложений, отдельно увеличены девять ключевых пар; новое вступление — все 94 кадра. Сетка 16,8 мс содержит 1051 удержанный слот, без интерполяции исходника. Полное декодирование, TypeScript, воспроизведение двух версий и диагностики в Chromium, переходы по главам и переключатель плеера проходят. Проверены SHA исходников/клипов, точное совпадение декодированной сборки с клипами и 329 общих кадров вариантов. [Итоговый аудит](review.md) отделяет исправленное от оставшихся отличий: кисти/захват, кромка/клапаны, рисунки чертежа, вода и реквизит всё ещё требуют работы. Все 24 прежних замечания закрытыми не объявляются.

Аудио остаётся исходным сведённым AAC. Точное снижение **только** SFX на 15% и локальный CapCut не объявляются выполненными: раздельных дорожек и доступа к пользовательскому ПК нет. Субъективное прослушивание пока не выполнено. В соцсетях ничего не публикуется; большие файлы создаются на сервере вне Git.

## Воспроизведение на сервере

Из `../video/`: `npm run check`, затем `npm run render:v05`, `npm run render:v05:bts`, `npm run render:v05:book`, `npm run package:v05`, `npm run audit:v05`, `npm run check:v05:browser`. Chromium `/usr/bin/chromium`, FFmpeg/FFprobe, Python с Pillow; для повторного расчёта камер нужны NumPy/SciPy. Нужны исходные ресурсы v03/v04 из существующего asset manifest и файл смешанного звука v04. Тяжёлые клипы/ресурсы и `out/` не входят в Git; новый JPEG экрана камеры — наш контрольный рендер с сохранёнными пропорциями и чёрными полями внутри горизонтального дисплея.

Фиксированные параметры камер уже сохранены в `src/v05/*camera*.ts`; пересчёт не требуется для обычного рендера. Для исследования: `python scripts/fit_scene_v05.py` → `node scripts/fit_cameras_v05.cjs` → `python scripts/fit_details_v05.py`; чертёж отдельно `python scripts/fit_blueprint_v05.py`. Скрипты меняют параметры и отчёты, поэтому выполнять до рендера, проверив diff. В [calibration/cup-points.json](calibration/cup-points.json) сохранён именно использованный вход совместного расчёта; он предшествует последнему опусканию крыши клапанов. Итоговая геометрия проверяется изображением, а не объявляется точной из-за малого остатка оптимизатора. [Измерения света](calibration/light-rois.json) содержат области, яркость и нормированные огибающие: это яркость экранных пикселей, не ваттметрия.

Рендер сохраняет хеш исходников и каждого клипа; упаковка требует одной версии исходников для 15 базовых клипов. Первый план V05B и разворот V05C проверяются отдельными манифестами, которые ссылаются на тот же базовый хеш; перед упаковкой заново проверяются его исходники и все SHA файлов. Основная сборка берёт первый план V05B и разворот V05C, исходный тёмный план остаётся как история непринятого кандидата. Повторный запуск использует только проверенный кэш. Для локальной правки можно использовать `node scripts/render_v05.mjs --only=PourV05`, однако после изменения общих исходников полный отчёт должен снова содержать одну версию: смешивать клипы разных сборок нельзя.

## Последняя правка разворота

Нативное наложение выявило перевёрнутую верхнюю карту и слишком общую перспективную сетку. В V05C [штрихи и движение края](notebook-ink-report.json) восстановлены по всем 31 кадру f200–230. Это графический композитинг: маски содержат синтетические синие цвета и прозрачность отдельных штрихов, а не фотографические RGB бумаги, руки или комнаты. Совпадение штрихов не доказывает независимое восстановление геометрии нарисованной комнаты. Исходный автор — Austen Paul, ссылка есть в манифесте. Сами бумага, рука, освещение и перелистывание рендерятся в 3D.

Камера подгоняется под верхний край и переход у корешка; в четырёх слабо видимых кадрах положение корешка интерполировано, погрешность отмечена в отчёте. Это экранные ограничения, не метрическое восстановление камеры автора. Для мягкой тени используются четыре точки источника размером 95 × 120 мм вместе с четырьмя субкадрами движения; яркость верхнего поля ограниченно корректируется по измеренным областям с затуханием к нижнему полю.

Актуальная монтажная композиция — **EditV05C**: `npm run studio:v05`, порт 3031. Старые композиции сохранены как история. Экспорт делает FFmpeg по проверенным клипам; опубликованная конфигурация облачной среды не менялась.
