# LAB-R001 / v02 — короткая проба готова

Дата: 2026-11-06. Основание: D019, следующая попытка после оценки v01. [Задача и этапы](brief.md), [технический отчёт](report.json), [исходный проект](../video/README.md).

**Готов отдельный MP4 на 5 секунд:** `/workspace/shared/downloads/LAB-R001-v02-light.mp4`. Это короткая проба модели, материала и света; исходный 18-секундный v01 сохранён отдельно.

## Что изменилось

- В первом кадре сразу виден результат. Затем базовая модель с сеткой, материал и основной свет, контурный свет и финальный план.
- Крупный постоянный заголовок объясняет задачу: «Из модели — в предметный кадр». Нижняя подпись показывает этап.
- Предмет и свет помещены в нейтральную студийную среду. Из короткой пробы исключены вода, качающийся лист, карандаш и часы, на которых v01 теряла убедительность.
- Модель переделана отдельно: внутренний слой бумаги, более тонкий край, согласованные поверхности клапанов, фактура и печатная маркировка.
- Первые контрольные изображения выявили наложение предмета на заголовок и резкую границу фона. Исправлены камера и фон; корректировка вошла в готовый рендер.
- Новый собственный звуковой ассет: технически заметно громче v01, без заимствованной музыки. Субъективное прослушивание не выполнено.

## Проверки

MP4: **720 × 1280, 24 fps, 120 видеокадров / 5 секунд**. Контейнер с аудио — около **5,013 с**, размер **583 165 байт**. Кодеки H.264/AAC. Полный проход декодирования FFmpeg завершился без ошибок; TypeScript проходит.

Просмотрены 40 кадров с частотой 8 кадров/с по всей длительности и отдельные контрольные изображения базовой модели и результата. Заголовок, предмет и подписи разделены; все этапы присутствуют. Это покадровая оценка, не слуховой просмотр.

Звук: средний уровень около **−25,2 dBFS**, максимальный около **−3,8 dBFS**; клиппинга по измерению нет. Эти показатели не заменяют оценку звучания.

Готовый файл проверяется отдельно в серверном браузерном плеере `watch-v02.html`. Копия для Studio — `video/public/LAB-R001-v02.mp4`, постер — `video/public/poster-v02.jpg`. MP4 не включён в Git, код и небольшой звуковой ассет сохранены. [Отчёт](report.json) содержит хеш файла и результат браузерной проверки.

## Оценка результата и границы

Теперь яснее читается переход от модели к оформленному кадру. Студийная среда и компактный сценарий согласованы между собой. Результат остаётся стилизованной программной 3D-графикой; фотореализм не достигнут и не заявлен. Вклад перехода от простой модели к материалу заметнее, чем дополнительного контурного источника — это стоит учитывать в следующем разборе.

На этапе «материал и свет» меняются оба параметра, поэтому не выдавать сравнение за эксперимент с одной лампой. Заголовок, схема и финал показывают общий процесс оформления 3D-сцены. Полноценный обучающий выпуск и полный ремейк 18 секунд этой пробой не заменены.

v01 не изменена, её SHA-256 проверен. Все операции выполнены на сервере без новых зависимостей и готовых внешних стилей. Публикация в соцсети не выполнялась; просмотры и удержание этой пробой не проверены. C001-09 остаётся в работе до разбора текущего качества и выбора дальнейшей версии.

## Воспроизведение на сервере

Из `video/`:

```bash
npm ci
npm run studio
npm run check
npm run render:v02
npm run package:v02
```

Композиция Studio: `FoldLightV02`. Исходники v02 находятся в `video/src/v02/`; v01 использует прежние компоненты. Для пересоздания звука — `npm run assets:v02`. Команды упаковки требуют Python, NumPy и FFmpeg в существующей серверной среде.
