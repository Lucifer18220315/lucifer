# LAB-R001 / FOLD — самостоятельная 3D-версия

Серверный проект: **Three.js + React Three Fiber + Remotion**, звуковой ассет и проверка файлов через **FFmpeg**. Исходный Instagram-ролик в проект не включён. Материалы, геометрия, чертёж и маркировка создаются кодом; внешние стили пока не применялись. В v01–v03 звук собственный синтетический; для контрольной v04 сохранена дорожка референса с указанием источника, вне Git.

Референс: [Austen Paul, DcjNPkZB_KF](https://www.instagram.com/austen_paul/reel/DcjNPkZB_KF/). [Разбор и отличие адаптации](../brief.md), [таймлайн](../timeline.json).

## Запуск на сервере

Нужны Node.js, npm и Chromium; Python с NumPy и FFmpeg используются для пересоздания звука, технической проверки и упаковки результата. Доступ к пакетному реестру — через штатный прокси среды. Настройки облачной среды не изменялись.

```bash
npm ci
npm run studio
```

Предпросмотр: `http://localhost:3030/FoldStudy`. Studio содержит основной ролик и девять отдельных редактируемых сцен. Сервер в текущей сессии запущен; сохранность запущенного процесса после завершения среды не гарантируется. Большие результаты не заменяют код в Git.

```bash
npm run check
npm run render
npm run package
```

Основная композиция: 1080 × 1920, 24 fps, 432 кадра, **18 секунд**. Экспорт первой версии: **720 × 1280**, масштаб 2/3. Внутренний WebGL DPR тоже 2/3, чтобы не растеризовать скрытое более высокое разрешение на CPU сервера. Это нативный экспорт первой версии, не заявление о Full HD. Файл: `out/LAB-R001.mp4`.

Полный размер композиции можно менять вместе с WebGL DPR и масштабом экспорта; снятие только флага масштаба не восстанавливает детали 1080p. Для дальнейших версий эти параметры менять согласованно.

```bash
npm run assets
```

Команда воспроизводит собственный звук бумаги, переключений, воды и карандаша. Используется детерминированный генератор, временный WAV удаляется после кодирования AAC. Готовый небольшой `public/sound-design.m4a` включён в проект, чтобы обычный `npm ci` не требовал Python.

## Файлы

- `src/Objects.tsx` — стакан, стол, бумага, карандаш, часы.
- `src/textures.ts` — процедурные текстуры и собственная печатная графика.
- `src/Stage.tsx` — свет, камера и движения, привязанные к кадру Remotion.
- `src/scenes/` — девять сцен, каждая открывается отдельно в Studio.
- `src/Film.tsx` — последовательность сцен и звуковая дорожка.
- `src/Root.tsx` — регистрация основного видео и сцен.
- `scripts/sound_design.py` — воспроизводимый звук без заимствованной музыки.
- `scripts/package_video.py` — проверка, faststart-упаковка, постер, раскладка и копия в серверную папку скачивания.
- `public/watch.html` — просмотр готового файла с переходами между сценами; открывается из Assets Studio после упаковки.

Работа ведётся на сервере. `node_modules`, кэш, промежуточные картинки и MP4 не включаются в Git. Не выполнять команды на Mac пользователя автоматически.

## Практические ограничения

Это программная 3D-адаптация, не реальная съёмка. Стакан и струя воды моделируются геометрией; полноценная физическая симуляция жидкости не выполняется. В v01–v03 ракурсы, чертёж, маркировка и часть движений были самостоятельными. После D021 это не считается достаточным повторением; актуальная сверка v04 выделяет оставшиеся неточности переноса. Наличие рендера не подтверждает локальную новизну формата или будущие просмотры.

Звук создан и технически проверяется по файлу; субъективное прослушивание помощником недоступно в текущем интерфейсе. Окончательный баланс звука требует просмотра пользователем. Перед публикацией отдельно оценить целостность движения и качество модели. Публикация не поручена.

## Версия 03

[Задание, причины, проверки и команды воспроизведения](../v03/README.md). Новая композиция `FoldLightV03` сохраняет насыщенное окружение и показывает один контролируемый приём света.
