## Источники и инструменты

Живая съёмка взята на Pexels: [авторы, страницы, прямые файлы и SHA](assets.json). Проверена [лицензия](https://www.pexels.com/license/): разрешены бесплатное использование и модификация, запрещены приписывание одобрения людям/брендам и продажа неизменённых исходников. Стоковые актёры не изображают пользователя. Монтаж и 2D-графика собраны специально для этих проб.

Canva/Adobe пользователь указал тегами и сообщил, что они включены. Повторный поиск в доступных инструментах и навыках не предоставил агенту их вызовов; команды активации этих приложений здесь нет. Они не использовались. Настройки аккаунта пользователя и опубликованная конфигурация облачной среды не менялись. Photoshop на стоковом экране не означает использование Adobe агентом. Применены доступный Remotion-плагин, FFmpeg, Chromium/Playwright и Python/Pillow/NumPy. Новые зависимости не устанавливались. [Реестр возможностей/лицензии](tools-and-license-check.json).

Музыка и эффекты синтезированы самостоятельно, раздельные дорожки сохранены на сервере. В миксе только SFX имеют коэффициент0,85, музыка1,0: [параметры](audio.json). Исходный звук Pexels не используется. Проба02 использует синтезированные звуковые акценты, не настоящий синхронный фоли.

В №10 снята настоящая работа локального деморедактора: изменение насыщенности и экспорт клипа через FFmpeg. [Команда, время и проверенные144 кадра](screen-operation.json). Запись ускорена×2,08; ожидание сокращено, готовый результат действительно создавался.

## Воспроизведение на сервере

Код — `../episodes/LAB-R001/video/src/style-tests/`, отдельный вход `index.tsx`. В нём нет моделей, ThreeCanvas или объёмных CSS-разворотов. Из `video/`:

```sh
python scripts/prepare_style_assets.py
python scripts/capture_style_screen.py
```

Для ускоренной записи взять путь из `out/style-screen/capture-path.txt`, убрать первые0,4с, применить `setpts=0.48*(PTS-STARTPTS),fps=24,tpad=stop_mode=clone:stop_duration=1` и сохранить144 кадра как `public/style-tests-assets/screen-capture.mp4` через FFmpeg. Затем:

```sh
npm run check
npx remotion studio src/style-tests/index.tsx --no-open --port=3032
node scripts/render_style_tests.mjs --controls
node scripts/render_style_tests.mjs
python scripts/package_style_tests.py
python scripts/check_style_tests.py
```

Для браузерной записи используется установленный системный FFmpeg через временный путь Playwright внутри `out/`, без установки нового пакета. Большие исходники/дорожки/рендеры/build исключены из Git; источники и генерация воспроизводятся сохранёнными командами. Настройки опубликованной среды и Mac не меняются.
