## Как читать статусы

- **Факт со слов пользователя** — предоставленная информация, ещё не обязательно проверенная по источникам.
- **Решение** — явно выбранное пользователем правило или направление.
- **Предложение** — рекомендация помощника, которая ещё не стала решением.
- **Гипотеза** — предположение, для которого определена проверка.
- **Проверено** — есть конкретный источник, материал или результат выполненной проверки.

Правила платформ, аккаунты и финансовые гипотезы пока не исследованы. Наличие документа об исследовании не означает, что исследование завершено.

Не хранить здесь пароли, токены, закрытые методы работы, персональные данные клиентов и тяжёлые видеоисходники. Эта база помогает продолжать работу между сессиями; она не означает переобучение модели или фоновое наблюдение за аккаунтами.
