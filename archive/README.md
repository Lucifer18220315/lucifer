# Архив

Завершённых циклов пока нет. C001 остаётся активным.

После заполнения итогового разбора переносить закрытый цикл в `archive/cycles/Cxxx/` либо оставлять в исходном месте с явным статусом «закрыт». Выбрать один способ для конкретного переноса, обновить все ссылки и STATUS. Не удалять доказательства результатов и причины отмены задач.
