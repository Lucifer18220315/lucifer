# Журнал подтверждённых решений и требований

Источник начальных записей D001–D012 — разговор 2026-11-05. D013–D015 добавлены 2026-11-06. Новые записи дописывать; замены помечать ссылкой на следующее решение.

| ID | Решение/условие | Основание и последствия |
| --- | --- | --- |
| D001 | Playboy — рабочее название | Публичное использование ещё требует проверки названия и позиционирования |
| D002 | Развивать несколько тематических блогов | Разделять жизнь/зал, рынки, готовку и автоматизации; порядок запуска не выбран |
| D003 | Хранить рабочую память, задачи, правки и результаты в Git | Пользователь должен находить материалы без участия чата |
| D004 | Вести последовательные циклы с оценкой результата | Статусы, критерии выполнения, итоги и корректировка перед следующим циклом |
| D005 | Учитывать около 16 часов работы пользователя в день | Исправляет ошибочную оценку «в неделю»; фактическую скорость ещё предстоит измерить |
| D006 | Начать с минимального бюджета | Не считать это согласованием какой-либо платной покупки |
| D007 | Пользователь готов показывать лицо и использовать голос | Для live — русский язык; для записанных материалов допустима адаптация на другие языки |
| D008 | Не раскрывать секреты текущей рыночной работы | Использовать только разрешённые публичные аспекты опыта |
| D009 | Помощник должен критиковать и проверять предположения | Не выдавать гипотезы за факты и не соглашаться автоматически |
| D010 | Ориентир первого месяца — 2026-12-05 | Рост аудитории, первая монетизация либо первые продажи; продукт пока неизвестен |
| D011 | Не применять прежние настройки среды повторно и не публиковать среду | Указание после последней публикации; обычное сохранение документов в Git — отдельная операция |
| D012 | Сохранить обсуждённую базу в Git | Последнее поручение пользователя прямо разрешает создание документов, коммит и отправку в выбранный репозиторий |
| D013 | Для каждого аккаунта искать и адаптировать форматы с других рынков, включая неанглоязычные | Пользователь хочет переносить зарубежные форматы на русскую аудиторию, а российские — например, на испанскую; проверять локальную распространённость и жизнеспособность адаптации. [Процесс](../workflows/format-transfer.md) |
| D014 | Текущий поиск зарубежных конкурентов проводить в Instagram и по Reels | Уточнение пользователя 2026-11-06: не расширять эту задачу на YouTube. Другие площадки остаются в общем брифе, но не подменяют Instagram-исследование |
| D015 | Искать узкие повторяемые зарубежные Instagram-серии с хотя бы 100 тысячами просмотров на видео | Уточнение пользователя 2026-11-06. Проверять несколько выпусков одной серии, фиксировать результаты ниже порога и размер выборки; просмотры не равны уникальному охвату. Порог относится к отбору источников, не является обещанием пользователю |

Правила архивирования, объём первого теста и порядок запуска, предложенные помощником, см. отдельно: [предложения](proposals.md).
